# Chicago payment workbook

The XLSX is a populated snapshot of the pinned real-data extract. Annual review formulas reconcile positive and negative USD to net disclosures. Vendor review shows the latest-year top 50 names against the full positive-value denominator; names are not resolved legal entities. Review queue statuses and notes are editable.

The PNGs are artifact-engine workbook renders, not Microsoft Excel screenshots. Native Excel execution was not tested. The optional builder requires the OpenAI artifact-tool runtime; opening the XLSX and running the Python analysis do not. Power Query M can be pasted into a blank Excel/Power BI query after setting ReportFolder.
